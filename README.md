# CNN Traffic Sign Classification Using FPGA

## Project Description

This project implements a Convolutional Neural Network (CNN)
for traffic sign classification using Verilog on FPGA.

The system classifies four different traffic sign categories
using 32x32 pixel images.

## Classification Categories

- STOP
- NO ENTRY
- GIVE WAY
- TURN LEFT

## Technologies

- Python
- Google Colab
- Convolutional Neural Network (CNN)
- Verilog HDL
- Quartus
- ModelSim

## Dataset Specifications

- Image size: 32x32 pixels
- Image format: BMP
- Number of classes: 4
- Total images: 4000
- Dataset type: Synthetic
